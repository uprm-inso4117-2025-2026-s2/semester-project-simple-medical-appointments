===== *Design Decision: `DailyAvailability(slot_minutes=0)`*

[.changed]#Feedback asked whether invalid `DailyAvailability` objects should be impossible to construct instead of relying on runtime `ValueError`.#

[.changed]#Current branch behavior: validation occurs in service execution (`generate_available_slots`) and in `TimeRange.split`, where `slot_minutes <= 0` raises `ValueError`.#

[.added]#Alternative considered: enforce the invariant at object construction (for example, a `__post_init__` check in `DailyAvailability`) so invalid instances cannot exist at all.#

[.changed]#Rationale for current state: the existing implementation centralizes guard checks at operation boundaries; this kept iterations small and matched existing tests.#

[.added]#Refinement opportunity: move or duplicate the guard into `DailyAvailability` construction to strengthen type-level domain safety while preserving current tests.#
