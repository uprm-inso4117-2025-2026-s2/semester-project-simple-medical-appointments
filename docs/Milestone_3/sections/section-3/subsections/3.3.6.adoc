==== *Mutation Testing*

[.changed]#This subsection separates mutation-testing scope for backend domain logic from frontend/UI behavior. Mutation analysis here is scoped to backend source code and backend tests only.#

===== *Correct Mutation-Testing Target*

[.changed]#Mutation testing must mutate production code while keeping tests unchanged. The previous approach that mutated test files is not valid for judging test-suite adequacy.#

[.changed]#For this branch, the primary production target is backend scheduling logic in `backend/app/services/scheduling.py`, exercised by `backend/tests/unit/test_scheduling.py`.#

[.changed]#The target set should be expanded incrementally as executable unit coverage exists for each module.#

===== *Result Reporting Format*

[.changed]#Text-based mutation findings are reported as tables, not screenshots, for traceability and reviewability in version control.#

[cols="1,2,2,2", options="header"]
|===
| Mutant outcome | Interpretation | Action | Confidence impact

| Killed
| Tests detected injected fault
| Keep current assertions; use as regression guard
| Increases confidence for covered behavior

| Survived
| Tests did not detect injected fault
| Add/strengthen assertions or missing scenario
| Reveals concrete gap

| Equivalent / non-actionable
| Mutation does not change observable semantics
| Document and exclude from score interpretation
| Neutral
|===

===== *Score Interpretation Policy*

[.changed]#A mutation score below 50% is treated as "limited adequacy with significant gaps," not as strong confidence.#

[.changed]#Any score statement in this project must be tied to the exact mutated source modules and test suites used in that run.#

===== *Bounded Conclusions*

[.changed]#Mutation outcomes support conclusions about test-suite effectiveness for mutated modules only; they do not justify broad claims about overall system reliability unless most relevant source modules are included.#

[.changed]#A valid project-level statement at current maturity is: "The backend test suite reflects implemented scheduling features for mutated backend modules, with remaining gaps identified by surviving mutants."#
