===== *Executable BDD Suite Size (Broadened)*

[.changed]#The repository now contains 7 executable BDD scenarios in the appointment booking feature, expanded from the earlier 3-scenario baseline.#

[cols="1,3,2", options="header"]
|===
| Scenario | Behavior Verified | Requirement References

| Patient successfully books an available appointment
| Request persisted, slot becomes unavailable
| <<REQ-BOOK-F-01>>

| Patient attempts to book an already-taken slot
| Conflict rejected (`409`), no second appointment
| <<REQ-BOOK-F-01>>

| Doctor cancels a scheduled appointment
| Appointment becomes `Cancelled`, slot is released
| <<REQ-BOOK-F-02>>

| Booking requiring insurance stays pending
| Appointment remains `PendingApproval` until prerequisites clear
| <<REQ-CONFIRM-F-01>>, <<REQ-CONFIRM-F-02>>

| Pending appointment confirmed after insurance authorization
| Status transition from `PendingApproval` to `Confirmed`
| <<REQ-CONFIRM-F-03>>

| Patient cannot reschedule below clinic cutoff
| Policy-based rejection near time boundary (e.g., 1:55 PM for 2:00 PM)
| <<REQ-BOOK-F-03>>

| Waitlisted patient gets released slot
| Cancellation-driven reassignment using waitlist ordering
| <<REQ-WAIT-F-01>>, <<REQ-WAIT-F-02>>
|===
